# OwnTally

Split expenses with friends on Android, with no server and no account.

- Everything is stored on your phone.
- Friends sync directly, in the same room or over the internet.
- Data is signed and end-to-end encrypted. An optional relay forwards encrypted bytes only.

Status: design stage. Read [docs/DESIGN.md](docs/DESIGN.md), then [docs/BUILD_PLAN.md](docs/BUILD_PLAN.md).
